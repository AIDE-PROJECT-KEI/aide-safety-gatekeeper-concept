# AIDE Safety Gatekeeper

### 確かめられるまで、AIは「行ってOK」と言わない

**AIDE Safety Gatekeeper** は、外出前のAIの推奨と、実際の行動判断との間に安全確認の境界を設ける、AIDE ARK GATEの将来構想です。

## アイデア

AIは限られた情報からでも、もっともらしい推奨を返すことがあります。しかし、天候や規制は変化し、本人の経験や技能によって安全な条件も異なります。

AIの「行けそう」という提案をそのまま確定せず、必要な前提を確かめられない場合は、判断を保留する仕組みを目指します。

## 想定する流れ

1. 利用者がGeminiに「サーフィンに行ってもよいか」と相談します。
2. Geminiが、手元の情報をもとに推奨候補を提示します。
3. AIDE ARK GATEが、最新の風向・風速、落雷注意報、遊泳・サーフィン規制、本人の技能との適合を確認する構想です。
4. 条件を確認できない場合は **HOLD（保留）** とし、必要な情報がそろった後に再評価します。
5. 最終的に行くかどうかを決めるのは本人です。

## AIの役割と実行境界

* **Gemini**：利用者の相談に対して推奨候補を提示します。その回答だけで行動を決定しません。
* **AIDE ARK GATE**：推奨とは独立して、判断に必要な前提の確認と保留を担う構想です。
* **利用者**：必要な情報を確認し、最終判断を行います。

## 応用の可能性

同じ考え方を、登山、海水浴、車の運転、台風時の外出など、状況の変化や本人の技能が安全に関わる判断へ広げることを想定しています。

## 現在の範囲と注意事項

このリポジトリは**将来構想の説明資料**です。気象・規制情報との連携、本人の技能評価、安全判定機能は実装していません。動画内の画面と応答文は架空のイメージで、実際の気象情報や規制情報に基づく安全判断を行うものではありません。

実際のGemini連携確認は、架空の送金依頼を使った別のデモで行っています。このデモは、本リポジトリのアウトドア安全機能を実装したものではありません。

実際の外出判断では、このコンセプトデモに頼らず、最新の公式気象情報や現地の規制・注意情報を確認してください。
